How to use the generated file

  1. Download the generated file as platformio.ini.
  2. Copy it into LoRaWAN-HelloWorld-radiolib/.
  3. Build with pio run -e <environment-name>.
  4. Upload with pio run -e <environment-name> -t upload.
  5. Open the serial monitor with pio device monitor.
  6. Install ttn/payload-formatter.js in TTN to decode fPorts 1–5 and diagnostics.

LoRaWAN notes

LoRaWAN 1.1.0 uses separate network and application root keys. In this firmware that means AppKey and NwkKey are both configured.

LoRaWAN 1.0.1 uses the older OTAA key model. In this firmware the generated INI omits RADIOLIB_LORAWAN_NWK_KEY, so the C++ code passes nullptr for the network key.

DevEUI identifies the device and is generated as 0x... in the final PlatformIO build flag. JoinEUI is set to zero for the TTN sandbox setup used in this course. AppKey/NwkKey are secrets and must be unique per real device.
